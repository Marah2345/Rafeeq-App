# Rafeeq-App
Rafeeq is an AI-powered Arabic voice companion for elderly users in Saudi Arabia, enabling natural voice interaction for medication reminders, prayer, Quran, emergency support, health guidance, and daily assistance using Google AI technologies and Firebase. 
## Key Contributions & Role (Marah2345)

**Full-Stack & Firebase Integration:** Designed and developed the Reminders UI, integrated with Cloud Firestore for full CRUD operations (create, read, update, delete), and enabled Local Notifications.
**AI & API Integration:** Connected and integrated Gemini AI models along with Prayer Times API services into the app.
**Requirements & UX Engineering:** Defined both Functional and Non-Functional Requirements, and designed/optimized the User Experience (UX).
